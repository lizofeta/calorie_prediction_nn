# Предсказание калорийности блюд по фото и составу

Мультимодальная модель регрессии оценивает калорийность блюда (ккал) по фотографии, списку ингредиентов и массе порции. Проект включает исследовательский анализ данных, обучение и оценку модели в Jupyter Notebook.

## Постановка задачи

- **Тип задачи:** мультимодальная регрессия.
- **Целевая переменная:** `total_calories` - калорийность блюда в ккал.
- **Входы:** изображение блюда, текстовый список ингредиентов, масса блюда в граммах.
- **Метрика:** MAE (Mean Absolute Error), в ккал. Целевой ориентир - MAE < 50 на тестовой выборке.

Одна только масса не определяет калорийность: блюда одинаковой массы могут сильно различаться по энергетической плотности. Поэтому модель использует три модальности.

## Данные

В `data/` находятся:

- `dish.csv` - блюдо, масса, калорийность, список ID ингредиентов и исходный split (`train`/`test`).
- `ingredients.csv` - соответствие ID ингредиента его названию.
- `images/<dish_id>/rgb.png` - фотография блюда.

Для воспроизводимого запуска нужны исходные CSV и каталог изображений из `data/`. Текущая реализация ожидает их расположение и имена без изменений.

## Модель

Архитектура объединяет три представления:

1. **Текст:** предобученный `bert-base-uncased`. Размораживаются последние слои энкодера (10–11) и pooler.
2. **Изображение:** предобученный `tf_efficientnet_b0` из timm; верхние блоки размораживаются для дообучения.
3. **Масса:** стандартизированный скаляр проходит через MLP (`1 → 32 → 32`).

При обучении изображений применяются crop, горизонтальное отражение, случайный affine-поворот/масштаб/сдвиг и небольшие изменения яркости/контраста. Валидация и тест используют center crop и нормализацию из pretrained-конфигурации EfficientNet.

## Результаты

Значения приведены по сохраненным выводам запуска в `notebook.ipynb`.

| Выборка / этап | MAE, ккал |
| --- | ---: |
| Валидация, лучшая эпоха (30) | 36.26 |
| Тест | 44.01 |

Тестовый MAE укладывается в целевой ориентир < 50 ккал. Анализ ошибок показывает, что модель чаще занижает калорийность высококалорийных блюд (примерно выше 600 ккал); крупные абсолютные ошибки достигают порядка 300-500 ккал. Это ограничение важно учитывать при интерпретации среднего MAE.

Метрики относятся к зафиксированному прогону ноутбука и могут измениться при смене данных, версий библиотек, pretrained-весов или окружения.

## Запуск

Нужен Python 3.13+ и установленный [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run jupyter lab notebook.ipynb
```

Запускайте ячейки ноутбука последовательно. При первом обучении веса `bert-base-uncased` и `tf_efficientnet_b0` загружаются из Hugging Face Hub и timm, поэтому нужен сетевой доступ. Устройство выбирается автоматически: CUDA при доступности, иначе CPU. Параметры находятся в `scripts/config.py`.

Основные зависимости: PyTorch, Transformers, timm, Albumentations, scikit-learn, pandas, NumPy, Pillow, Matplotlib и TorchMetrics. Полный список — в `pyproject.toml` и `uv.lock`.
